# 船舶管理平台 · 颜色变量规范

更新日期：2026-10-22。已直接写入[现有 Figma 文件](https://www.figma.com/design/h1PuegSzztQAbaAS4MDsx4/%E9%A1%B5%E9%9D%A2?node-id=0-1)。

## 变量结构

| 集合 | 模式 | 数量 | 用途 |
| --- | --- | ---: | --- |
| Primitives · 基础色 | Value | 59 | 保存设计稿精确 RGBA；基础色不出现在属性变量选择器中 |
| Color · 语义色 | Light | 62 | 页面设计使用；全部通过 Alias 引用基础色 |

基础色包含 56 种已使用的颜色/透明度组合，以及 3 种仅出现在渐变色标中的补充色。包含 15 个 legacy 存量/装饰色；不构造原稿中不存在的完整色阶。

## 使用规则

1. 新页面从 Color · 语义色选择变量：背景用 color/bg，文字用 color/text，边框用 color/border，图标用 color/icon。
2. 主操作和链接统一采用 #165DFF（color/action/primary、color/text/link）；#035DFF 继续用于原稿品牌图标；#0065EB 用于航线进度和蓝色渐变起点。原按钮 #0063F4 保存在 legacy 中，尚未批量替换原页面。
3. 岗位标签使用 color/tag/role；船舶业务状态使用 color/vessel。即使当前同色，也分别维护语义，以便未来独立调整。
4. 通用 warning 为基于原稿现有金色提出的语义规范，在变量说明中标记为建议用途。错误色来自原稿必填星号；没有补造浅红底或 hover、pressed 色值。
5. 原始色值维护在 Primitives，语义用途维护在 Color。新语义优先引用已有基础色，不重复录入色值。
6. legacy 分组用于存量还原、插画细节、一次性差异色；新页面优先使用语义变量。数字为本文件内部色值层级标识，不是补齐的标准等距色阶。
7. 渐变整体使用 Paint Style；渐变色标颜色使用 COLOR 变量。颜色修改沿“基础色 → 语义色 → 渐变色标”生效；方向和位置在样式中维护。

## 渐变样式

| 样式 | 色标 | 用途 |
| --- | --- | --- |
| `Gradient/Navigation/Dark` | #181B1F @ 0% → #292E34 @ 100% | 深色顶部导航（原稿出现 10 次） |
| `Gradient/Section/Blue` | #0065EB @ 0% → #1890FF @ 100% | 表单分区标题竖条（原稿出现 3 次） |

两种渐变均保留原稿 gradientTransform、透明度、混合模式和色标位置；4 个色标绑定相应的 color/gradient 变量。整体渐变保存在样式中，未创建伪装渐变的字符串变量。

## 来源与验证

扫描 Page 1 中的船员档案、船员详情、新建船员档案、航线跟踪、航线详情、船舶详情，共 6 个主要页面，以及可见实例子层的填充和描边。图片像素与隐藏图层不纳入界面用色变量。

- 已持久化：2 个集合、121 个 COLOR 变量、2 个 Paint Style。
- 62 个语义 Alias 均可解析；基础色 scopes=[]，语义色按用途设置 scopes，无 ALL_SCOPES。
- 121 个变量均具有用途说明及 WEB code syntax（var(--...)）；CSS 名称由本规范命名生成，未宣称已与生产代码同步。
- 两种渐变均通过原稿矩阵、RGBA 和色标位置一致性检查，4 个变量绑定有效。
- 现有画布图层改动数为 0；变量和样式供后续新页面选择使用，原页面尚未批量绑定。

完整精确 RGBA、Figma IDs 和保存结果见 [design-system-state.json](design-system-state.json)。HEX 仅为阅读展示，实际变量保留原始浮点 RGBA。
